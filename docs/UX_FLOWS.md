# User flows
## Choose a visual finish
Graphite hero -> click Sage or Pearl -> product image and pressed state change. Decorative circle and callouts remain real CSS/HTML.
## Explore models
Model photo or Explore model -> selected model's detail dialog -> Arrange a test ride -> enquiry preview with preferred model selected. No specifications are invented.
## Enquire
Book a test ride -> preferred-model selector -> preview disclosure. Actual dealership contact is required before an enquiry can be sent.
## Mobile navigation
Menu button -> navigation panel -> anchor choice -> navigation closes.
## Support and legal
Charging guide / Service & warranty -> matching FAQ opens.
Privacy / Terms -> informational preview dialog.
## Close overlays
Back/close button, Escape or click outside -> dialog closes and trigger focus is restored.
